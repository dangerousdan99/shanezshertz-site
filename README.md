# shanezshertz-site

The Shanez Shertz homepage, live at `shanezshertz.shop`. A static one-pager — no build step, no framework, no JavaScript.

## Structure

- `docs/` — served by GitHub Pages (custom domain via `docs/CNAME`).
- `docs/index.html` — the page.
- `docs/404.html` — custom not-found page.
- `docs/styles.css` — all styling.
- `docs/assets/` — logo and hero banner.

## Updating

Edit the HTML/CSS directly, commit, and push — GitHub Pages redeploys automatically.
